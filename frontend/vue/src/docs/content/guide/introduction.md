## Welcome

This documentation site provides guides and conventions for the uni-link frontend — a Vue 3 application built with an opinionated, production-ready foundation.

## What is This Project?

This is a Vue 3 starter that gives you everything needed to build modern web applications immediately, with carefully chosen tools and patterns that work together seamlessly.

## Why This Starter Kit?

Instead of starting from scratch and spending time configuring tools, this starter kit gives you:

| Feature | Description |
|---------|-------------|
| **Modern Tech Stack** | Vue 3, Vite, Tailwind CSS 4, TypeScript, and best-in-class libraries |
| **Opinionated Architecture** | Clear separation of concerns: Components → Composables → Services → Backend |
| **Component Library** | Accessibility-first components built with Reka UI for better UX |
| **Form Handling** | Recommended patterns using VeeValidate and Zod |
| **Data Fetching Strategy** | TanStack Query for server-state management |

## What's Next?

Explore the guides to understand our philosophy, folder structure, and coding conventions. Each section includes practical examples and production-ready patterns.
